This page is used for downloading _**plugins**_ and _**themes**_ from [yungsamd17/BetterDiscordAddons](https://github.com/yungsamd17/BetterDiscordAddons) repository.

## Usage

Single file:

```
/downloader/?plugin=PluginName
/downloader/?theme=ThemeName
```

Batch (files download one after another; the browser may ask permission to
download multiple files):

```
/downloader/?plugin=PluginA&plugin=PluginB&theme=ThemeC
```

You can also pass a raw repository path or full URL with `?url=`.
